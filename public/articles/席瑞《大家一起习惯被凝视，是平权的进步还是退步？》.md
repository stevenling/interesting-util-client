# 《大家一起习惯被凝视，是平权的进步还是退步？》席瑞
<font style="color:rgb(0, 0, 0);">真的听不下去了，有些男性就是对女性的理解如此之肤浅，各位我们来说一说什么叫做真正的凝视。</font>  
  
<font style="color:rgb(0, 0, 0);">你们真的觉得在这个社会里面，女性和男性被凝视的感觉是一样的吗？</font>  
  
<font style="color:rgb(0, 0, 0);">我们生活场景怎么凝视女性，你不美！</font>  
  
<font style="color:rgb(0, 0, 0);">哪怕你学历高，但是你不美，好可惜！</font>  
  
<font style="color:rgb(0, 0, 0);">哪怕你会挣钱，事业有成，你像董明珠，但是你不美，好可惜！</font>  
  
<font style="color:rgb(0, 0, 0);">哪怕你会说话，但是你不美，好可惜！</font>  
  
<font style="color:rgb(0, 0, 0);">男人被凝视怎么样？男人很简单，他都习惯了，他根本不在乎，你说他长得不好看，我说不是！你说他长得不好看，我能挣钱，会挣钱就有女人，这个世界上每个男人都能找到自己自信的办法。</font>  
  
<font style="color:rgb(0, 0, 0);">可是对于女人的评价都是如此的单一，所以你发现没，同样的凝视，为什么在女人身上，你倒之以男人不可以实行。原因很简单，因为凝视的标准是在整个父权结构的背景下被设定的。</font>  
  
<font style="color:rgb(0, 0, 0);">凝视是一个哲学术语，它绝对不是简单的你看我一眼，或者我看你一眼这么简单，不然它不构成一个痛点，为什么我们要反对凝视，我想说，其实凝视它不是单独成立的，我们都在聊权力关系是哪个权力关系，是父权关系。</font>  
  
<font style="color:rgb(0, 0, 0);">也就是它在社会大背景之下来维护父权体制当中一个环节，凝视，它其实有两个，第一，它给有客体。第二，它给凝固。所以它必须是一个标准，而且它相对来说是，必须使这个标准不断重复再加以固定，说白了是为巩固父权制服务的，那么，它巩固的是父权制当中哪个部分？它巩固的是对男女在性别之维，因为这道题谈论的是性别之维的评价体系决定的。</font>  
  
<font style="color:rgb(0, 0, 0);">我们社会对男性的评价体系是什么体系？主要看重的是男人的社会性特征，你发现没？</font>  
  
<font style="color:rgb(0, 0, 0);">所以你发现在家庭埋怨的过程中，主要是说你有没有好工作，学业有没有成，事业有没有成，能挣几个钱？</font>  
  
<font style="color:rgb(0, 0, 0);">对于女性的评价主要基于哪个方面啊？生理性方面的对不对！</font>  
  
<font style="color:rgb(0, 0, 0);">其实你再想一想为什么这么分？父权制非常狡猾，还在这么分的过程中掌握资源的是谁？他逼着男性进步，我这里绝对不是冒犯各位男性，我知道男人生活很不容易，要达成这些标准也很不容易，因为他逼着男性必须掌握资源。</font>  
  
<font style="color:rgb(0, 0, 0);">而女性要掌握资源只有一种方式，就是你长得足够美，你服务于男性审美。我在生理性上对你做出评价。所以凝视，你女人用男人凝视女人的方法倒着凝视回去，没有用！</font>  
  
<font style="color:rgb(0, 0, 0);">男性不在乎我长得美不美观，我有什么关系？你说，那我凝视一下你的社会其他形态！没关系，我刚才讲了，每个男人都能找到自己可以成功的方法，所以他很自信。再不济怎么样呢，我比你懂得多对吧，你一定想从我这学点什么。</font>  
  
<font style="color:rgb(0, 0, 0);">所以你知道，女性这么凝视回去，她不成功。但是男人凝视女性为什么会造成这么大的伤害呢？</font>  
  
<font style="color:rgb(0, 0, 0);">这里面有一个最大的问题，就是凝视，它不是审美静观，不是说今天在地铁上看到这个女孩子，长得很好看就行了。</font>  
  
<font style="color:rgb(0, 0, 0);">而是什么呢？这个妞儿长得很好看，睡起来应该还是不错的，那个胸很大，摸一把还是很不错的，你千万别觉得邪恶，我在宿舍里面经常听到男性回去这么评价女性。</font>  
  
<font style="color:rgb(0, 0, 0);">你们自己想想是不是经常这么评价，因为在这个过程中性是带有占有欲望的。</font>  
  
<font style="color:rgb(0, 0, 0);">所以为什么女性害怕，因为性是带有攻击行为的。</font>  
  
<font style="color:rgb(0, 0, 0);">所以男性在怎么凝视女性？</font>  
  
<font style="color:rgb(0, 0, 0);">你最好美，但是不能所有人觉得你美，不然你就是骚浪贱。</font>  
  
<font style="color:rgb(0, 0, 0);">你最好美，而且你这个美必须得服务于我，如果你不挑选我，那是什么，那是你不识货，你看看我，我还是很行的。</font>  
  
<font style="color:rgb(0, 0, 0);">而且最主要的是：你美，但是你如果耽误了我的事，那你就是红颜祸水。</font>  
  
<font style="color:rgb(0, 0, 0);">所有的评价都是针对这样的一个分化的体系，形成的凝视。</font>  
  
<font style="color:rgb(0, 0, 0);">而为什么会出现这样呢，这是因为当性带有攻击性的时候，女性在公共领域当中，会有非常强烈的不安全感。</font>  
  
<font style="color:rgb(0, 0, 0);">你知道，今天我非常生气的一点是刚才对面不管是开玩笑也好，还是真心想的也好，说：“诶，大家来凝视我。”你看在男性眼里面凝视是一个玩笑，是一个笑话，他生怕你不凝视，是注意力的争夺。可是在女性这里，那是生命不能承受至今的无法言说。这种事情你说出来别人怪你矫情，不说呢，我难受。</font>  
  
<font style="color:rgb(0, 0, 0);">我再次强调，我们 8 位辩手，站在这里聊女性议题，一定要注意一个点，为什么我不倡导男性经常为女性发声，因为你真正的做不到理解那些感受，很多时候是有相隔的，经验与经验之间是有隔离的。那就是一种偏见的隐形的暴力。</font>  
  
<font style="color:rgb(0, 0, 0);">我见过最恶毒女性的评价就是：这个女生送给我，白送给我都不娶。你告诉我，你怎么凝视回去？你说：“哼！我看你长得这样我还不嫁呢！”凝视回去了吧？有用吗？你觉得反击到位了吗？</font>  
  
<font style="color:rgb(0, 0, 0);">好，第二种情况怎么凝视回去，我来看各种各样的资源，就你也配娶我？你给几个钱呀？你有彩礼吗？你看你凝视他的社会资源对不对？你凝视他的人脉，凝视他的地位，都不成功！为什么？</font>  
  
<font style="color:rgb(0, 0, 0);">这是一种自我物化，开始标价了！在这个过程中，为什么不成功？男性也会觉得很过分，说女性要彩礼。</font>  
  
<font style="color:rgb(0, 0, 0);">为什么不成功？</font>  
  
<font style="color:rgb(0, 0, 0);">因为在这个过程中，相互凝视相互报复带来的是性别之间的对立和刻板印象的加剧，他没有办法真正的解决问题。</font>  
  
<font style="color:rgb(0, 0, 0);">怎么解决问题？要让男性懂女性的痛！绝对不是说我必须也让他痛，这种同态复仇的方法早就不适用。</font>  
  
<font style="color:rgb(0, 0, 0);">用什么，用教育和文艺作品！多拍女性电影啊各位，女性电影不是凝视，我见过最好的女性电影就是《送我上青云》，关注自我成长，那种意识流的视角，让我看到中国女性电影的希望，她告诉我们，有一种电影，女性电影强调灵动性，没有审美课题，关注自我领域与自我表达同样可以获得人们的尊重。</font>  
  
<font style="color:rgb(0, 0, 0);">我们可以靠文艺作品和教育重新夺回领地，因为这件事情和知识无关和人品有关！</font>
