英语最简单的句子是基本句，也称为简单句（Simple Sentence）。

## 一、<font style="color:rgba(0, 0, 0, 0.9);">主谓 （</font>S + V） 句型
「主语 + 谓语」句型。

主语可以是人或物，谓语是一个动作，这个动作没有承受者，是一个不及物动词（intransitive verb），后面不需要跟直接宾语。

She runs. （她跑步。）

<font style="color:rgba(0, 0, 0, 0.9);">Time </font>**<font style="color:rgba(0, 0, 0, 0.9);">flies</font>**<font style="color:rgba(0, 0, 0, 0.9);">.（光阴似箭。）</font>

补充：及物动词的动作必须施加于一个对象上，意义才完整，可以有被动语态，宾语变主语即可。	

不及物动词动作不施加于对象，或者自身意义已完整，不需要宾语，一般没有被动语态。

例如 <font style="color:rgb(15, 17, 21);">appear（出现）， exist（存在）， happen（发生），arrive（到达）， come（来）， go（去）， fall（落下），smile（微笑）， laugh（笑）， cry（哭），die（死亡）， belong（属于）， sleep（睡觉）， sit（坐）， lie（躺）， rain（下雨）。</font>

47% 的动词即是及物动词又是不及物动词。

## 二、主谓宾 S + V + O 句型
「主语 + 谓语 + 宾语」句型。

宾语在句子中一般是动作的承受者。

<font style="color:rgba(0, 0, 0, 0.9);">I </font>**<font style="color:rgba(0, 0, 0, 0.9);">eat</font>**<font style="color:rgba(0, 0, 0, 0.9);"> rice. （我吃饭。）</font>

## <font style="color:rgba(0, 0, 0, 0.9);">三、主系表 S + V + C 句型</font>
「主语 + 系动词 + 表语」句型。

**<font style="color:rgba(0, 0, 0, 0.9);">系动词</font>**<font style="color:rgba(0, 0, 0, 0.9);">（be/变得/看起来/听起来等）+ </font>**<font style="color:rgba(0, 0, 0, 0.9);">表语</font>**<font style="color:rgba(0, 0, 0, 0.9);">（说明主语的身份、状态、特征）</font>

<font style="color:rgba(0, 0, 0, 0.9);">You </font>**<font style="color:rgba(0, 0, 0, 0.9);">look</font>**<font style="color:rgba(0, 0, 0, 0.9);"> tired.（你看起来很累。）</font>

<font style="color:rgba(0, 0, 0, 0.9);">主语</font>**<font style="color:rgba(0, 0, 0, 0.9);">具有</font>**<font style="color:rgba(0, 0, 0, 0.9);">表语特征。</font>

## 四、主谓双宾 <font style="color:rgba(0, 0, 0, 0.9);">S + V + IO + DO 句型</font>
「主语 + 谓语 + 间接宾语 + 直接宾语」句型。

<font style="color:rgba(0, 0, 0, 0.9);">He bought </font>**<font style="color:rgba(0, 0, 0, 0.9);">me</font>**<font style="color:rgba(0, 0, 0, 0.9);"> a coffee.（他给我买了一杯咖啡。）</font>

<font style="color:rgba(0, 0, 0, 0.9);">me 是间接宾语，a coffee 是直接宾语。</font>

另外一种句型的变形是：

<font style="color:rgba(0, 0, 0, 0.9);">即</font>**<font style="color:rgba(0, 0, 0, 0.9);">介词形式的间接宾语结构</font>**<font style="color:rgba(0, 0, 0, 0.9);">（Prepositional Indirect Object）</font>

## <font style="color:rgba(0, 0, 0, 0.9);">五、主谓宾补 (S + V + O + C) 句型</font>
「主语 + 谓语 + 宾语 + 宾语补足语」句型。

宾语补足语（Object Complement，简称 OC 或 C）用来补充说明宾语的身份、状态或特征。

宾语和补足语之间存在逻辑上的主谓关系（即"宾语是/变成/被认为是什么"）。

<font style="color:rgba(0, 0, 0, 0.9);">We made </font>**<font style="color:rgba(0, 0, 0, 0.9);">him</font>**<font style="color:rgba(0, 0, 0, 0.9);"> </font>**<font style="color:rgba(0, 0, 0, 0.9);">monitor</font>**<font style="color:rgba(0, 0, 0, 0.9);">.（我们选他当班长。）</font>

<font style="color:rgba(0, 0, 0, 0.9);">monitor 是宾补，修饰宾语 him。</font>
