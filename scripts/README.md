# 文章配置生成脚本

## 功能说明

`generate-articles-config.js` 脚本可以自动扫描 `public/articles` 目录下的所有 Markdown 文件，并自动生成 `src/config/articles.js` 配置文件。

## 使用方法

### 方式一：使用 npm 脚本（推荐）

```bash
npm run generate-articles
```

### 方式二：直接运行 Node.js 脚本

```bash
node scripts/generate-articles-config.js
```

## 脚本功能

1. **自动扫描**：扫描 `public/articles` 目录下的所有 `.md` 文件（排除 `README.md`）

2. **智能解析文件名**：
   - 支持格式：`作者《标题》.md` → 自动提取作者和标题
   - 普通格式：`标题.md` → 标题作为标题，无作者

3. **自动提取描述**：
   - 读取文件内容的前几行
   - 自动移除 HTML 标签和 Markdown 格式符号
   - 提取前 100 个字符作为描述

4. **自动生成 ID**：
   - 使用 `article1`, `article2`, `article3` 等格式
   - 按文件修改时间排序（最新的在前）

5. **自动获取日期**：
   - 使用文件的修改时间作为发布日期

## 文件命名规范

### 带作者信息的文件

文件名格式：`作者《标题》.md`

示例：
- `刘勃《商鞅黑洞》.md` → 标题：商鞅黑洞，作者：刘勃

### 不带作者信息的文件

文件名格式：`标题.md`

示例：
- `期末考试.md` → 标题：期末考试，无作者

## 注意事项

1. **不要手动修改** `src/config/articles.js` 文件，该文件由脚本自动生成
2. 添加新文章后，运行脚本即可自动更新配置
3. 脚本会按文件修改时间倒序排列文章（最新的在前）
4. 如果文件内容无法提取描述，会使用"暂无描述"作为默认值
